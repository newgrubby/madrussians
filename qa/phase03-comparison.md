# Phase 03 — Before / After

## Hero

- Increased the two-line display scale and tightened its offset so the title and photograph lead the viewport.
- Reduced the visual weight of route microcopy, header links, rules, and side navigation.

## Expeditions

- Increased card height and made the active card expand decisively with restrained sibling dimming.
- Kept metadata quiet by default; active/focus states restore exposure, hierarchy, dates, price, and CTA.

## Story

- Reduced the composition from six media tiles to five purposeful foreground/background layers.
- Enlarged and deliberately offset the headline to create a poster-like middle state; mobile uses its own static composition.

## Format

- Rebalanced the desktop columns around a larger image stage and tighter editorial index.
- Restored a true single-column mobile layout so the image stage occupies the full available width.

## CTA

- Increased headline authority and reduced form spacing while preserving the existing honest demo behavior.
- Kept the photographic finale and cyan action as the dominant closing hierarchy.
